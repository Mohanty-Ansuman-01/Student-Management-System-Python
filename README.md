# Student Management System Using Python

## Project Description

A console-based Student Management System developed using Python, Object-Oriented Programming (OOP), and custom exception handling.

## Features

* Student Registration
* Student ID Validation
* Duplicate Student Detection
* Marks Entry
* Grade Calculation
* Attendance Validation
* Individual Student Report Card
* All Student Reports

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Dictionaries
* Custom Exceptions
* Exception Handling

## Custom Exceptions

1. InvalidStudentIDError
2. InvalidMarksError
3. AttendanceShortageError
4. DuplicateStudentError

## Grading System

* 90–100: A+
* 80–89: A
* 70–79: B
* 60–69: C
* 50–59: D
* Below 50: F

## Attendance Requirements

Students must have at least 75% attendance.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open `main.py` in Spyder or another Python IDE.
4. Run the program.
